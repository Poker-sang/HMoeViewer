# 百度网盘客户端任务服务

本项目不引用 Viewer 或 Avalonia。调用 `IClientDownloadService.SendAsync` 时才发送任务。
`BaiduClientDownloadService` 在独立的无头 Edge 登录会话中读取分享页，动态发现并调用该页的官方下载 SDK。
它发送分享页根目录的全部文件／文件夹入口，保留原链接的查询参数；不复制爬虫的登录 Cookie。
支持新版 ES 模块页面和旧版 AMD 页面，分别从页面依赖图或资源映射发现官网 SDK，不点击下载按钮。

允许未登录时直接尝试发送；自动使用记录的提取码。每次发送完成、失败或取消后都关闭浏览器，不显示窗口；会话数据仍保存在登录目录中。需要人工验证时返回状态提示，由用户通过“打开链接”处理。
客户端也需安装并登录。发送成功表示官方 SDK 收到客户端接收回执，不表示文件下载完成。
如果要求验证码，返回 `NeedsVerification`，由用户在分享网页手动处理；目前没有实现客户端内部的 `nativeQuery` 桥接，也没有证明修改 UA 可以免验证码。
未确认送达时，重试前请检查客户端任务列表。

该接口依赖百度分享页的 SDK、页面元数据和客户端协议，网页更新时可能需要调整。
登录目录由调用方提供；服务复用此目录，每次发送释放浏览器，调用方在退出时负责 `DisposeAsync`。

验证采用拦截全部网络请求的 Edge 测试，覆盖参数保留、多文件、验证码与客户端回执分支。
用户已验证真实客户端能够接收任务。
